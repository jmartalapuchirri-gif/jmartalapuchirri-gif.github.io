Política de Privacidad

Qué es esta app

JMart Reels es una aplicación personal y automatizada que publica vídeos cortos (Reels/Shorts) en mis propias redes sociales (Facebook, Instagram y el canal de YouTube "JMart"), a partir de contenido que yo mismo genero y edito.

Es una herramienta de uso personal y automatizado que sube y programa vídeos cortos (Shorts) en el canal de YouTube "JMart", propiedad del mismo usuario que gestiona la app. No es una aplicación pública ni está disponible para terceros.

Política de Privacidad

Última actualización: 1 de octubre de 2026

Esta política de privacidad describe cómo la aplicación JMart Reels ("la app") accede y utiliza los datos de la cuenta de Google del propietario del canal de YouTube "JMart".

Qué datos utiliza: La app accede exclusivamente al siguiente permiso de la API de YouTube: https://www.googleapis.com/auth/youtube.upload — permite subir vídeos al canal de YouTube autorizado. La app no accede a ningún otro dato de la cuenta de Google (no lee correo, contactos, archivos de Drive, ni ningún otro servicio), y no recopila datos personales de terceros ni de espectadores del canal.

Cómo se usan los datos: Los datos de autorización (un token de acceso) se utilizan únicamente para subir y programar la publicación de vídeos en el propio canal de YouTube "JMart", de forma automatizada, sustituyendo la subida manual que haría el propio propietario del canal.

Con quién se comparten los datos: Los datos no se comparten, venden ni ceden a ningún tercero. El único uso es la comunicación directa entre la app y la API oficial de YouTube (Google), en nombre del propio propietario de la cuenta.

Almacenamiento y conservación: El token de autorización se almacena de forma local y privada, y se usa exclusivamente para el funcionamiento descrito arriba. El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

Uso de los servicios de la API de YouTube: Esta aplicación utiliza YouTube API Services ("This application uses YouTube API Services"). Al usar esta app también se aplican la Política de Privacidad de Google y las Condiciones del Servicio de YouTube.
