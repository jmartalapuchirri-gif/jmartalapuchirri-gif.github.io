Politica de Privacidad

Que es esta app

JMart Reels es una aplicacion personal y automatizada que publica videos cortos (Reels/Shorts) en mis propias redes sociales (Facebook, Instagram y el canal de YouTube "JMart"), a partir de contenido que yo mismo genero y edito.

Es una herramienta de uso personal y automatizado que sube y programa videos cortos (Shorts) en el canal de YouTube "JMart", propiedad del mismo usuario que gestiona la app. No es una aplicacion publica ni esta disponible para terceros.

Politica de Privacidad

Ultima actualizacion: 1 de octubre de 2026

Esta politica de privacidad describe como la aplicacion JMart Reels ("la app") accede y utiliza los datos de la cuenta de Google del propietario del canal de YouTube "JMart".

Que datos utiliza: La app accede exclusivamente al siguiente permiso de la API de YouTube: https://www.googleapis.com/auth/youtube.upload — permite subir videos al canal de YouTube autorizado. La app no accede a ningun otro dato de la cuenta de Google (no lee correo, contactos, archivos de Drive, ni ningun otro servicio), y no recopila datos personales de terceros ni de espectadores del canal.

Como se usan los datos: Los datos de autorizacion (un token de acceso) se utilizan unicamente para subir y programar la publicacion de videos en el propio canal de YouTube "JMart", de forma automatizada, sustituyendo la subida manual que haria el propio propietario del canal.

Con quien se comparten los datos: Los datos no se comparten, venden ni ceden a ningun tercero. El unico uso es la comunicacion directa entre la app y la API oficial de YouTube (Google), en nombre del propio propietario de la cuenta.

Almacenamiento y conservacion: El token de autorizacion se almacena de forma local y privada, y se usa exclusivamente para el funcionamiento descrito arriba. El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

Uso de los servicios de la API de YouTube: Esta aplicacion utiliza YouTube API Services ("This application uses YouTube API Services"). Al usar esta app tambien se aplican la Politica de Privacidad de Google y las Condiciones del Servicio de YouTube.
